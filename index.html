System Tools

Performance + Background Apps + Game Mode UBAH TAMPILAN

Matiin efek visual Windows, blokir app background, nyalain Game Mode. Tampilan Windows jadi lebih polos.

Detail
Apa itu
Matiin animasi/transparency, blokir app UWP jalan di background, aktifkan Game Mode.
Kenapa
Kurangi beban CPU/GPU dari efek visual & app yang diam-diam jalan di belakang.
Risiko
App Store (kalender, notifikasi) mungkin telat update. Perlu restart setelah merge.

Valorant Safe Optimization AMAN

Game priority, disable Game DVR, transparency, Xbox services. Tweak inti buat Valorant.

Detail
Apa itu
Naikkan prioritas GPU/CPU game, matikan Game DVR & transparency, matikan service Xbox yang jarang kepakai.
Kenapa
Game DVR & service Xbox makan resource walau gak dipakai.
Risiko
Sangat rendah — printer & Bluetooth gak disentuh, aman dipakai sambil kerja.

Disable Memory Compression CEK RAM DULU

Matikan kompresi RAM Windows. Cek RAM kamu dulu di Task Manager sebelum pakai.

Detail
Apa itu
Matikan fitur Windows yang otomatis kompres data di RAM.
Kenapa
Ringankan CPU di PC dengan RAM besar (16GB+), gak perlu compress/decompress terus.
Risiko
Jangan pakai kalau RAM di bawah 8GB — RAM lebih cepat penuh, malah bikin lag.

Latency Tweaks UBAH BOOT CONFIG

Disable Dynamic Tick & HPET, plus System Responsiveness ke 0. Mengubah konfigurasi boot Windows, bukan setting biasa.

Detail
Apa itu
Ganti sumber clock/timer sistem biar lebih presisi, dan set System Responsiveness ke 0 supaya CPU gak ngasih jatah reservasi buat task multimedia latar belakang saat game jalan.
Kenapa
Bisa kurangi micro-stutter di sebagian sistem — efeknya beda-beda tiap hardware.
Risiko
Ubah boot config lewat bcdedit & registry multimedia scheduler. Wajib restart setelah dijalankan. Kalau audio/video jadi patah-patah, balikin lewat tombol "Reset ALL to Default" atau reset manual (lihat catatan bawah halaman).

Disable Background Telemetry (DiagTrack) OPSIONAL

Matiin service Connected User Experiences & Telemetry (DiagTrack) dan dmwappushservice. Ini lebih ke debloat/privacy, bukan langsung nambah FPS.

Detail
Apa itu
Stop & disable service DiagTrack + dmwappushservice yang ngirim data diagnostik ke Microsoft, plus matiin autologger diagnostik.
Kenapa
Ngurangin proses background yang jalan diam-diam — efek ke FPS kecil, tapi lumayan buat PC yang berasa "berat" secara umum.
Risiko
Rendah, tapi bukan tweak wajib buat gaming — kalau ragu, skip aja bagian ini. Undo: sc config DiagTrack start= demand lewat Command Prompt admin.

Disable Background Apps (Global Toggle) AMAN

Matiin izin semua app UWP buat jalan di background lewat Settings, plus matiin background search indexing toggle.

Detail
Apa itu
Setara ke matiin toggle "Let apps run in the background" secara global lewat registry per-user.
Kenapa
App kayak Mail, Calendar, Store, dll gak lagi update/refresh diam-diam di belakang layar.
Risiko
Notifikasi dari app-app itu mungkin telat muncul. Undo: buka Settings → Privacy → Background apps, nyalain lagi manual.

Clean Temporary Files AMAN

Hapus folder Temp, Windows Temp, Prefetch. Cuma bersih file sampah, gak ubah setting apapun.

Reset ALL to Default UNDO

Balikin semua tweak registry di atas ke default. Pakai kalau mau mundurin semua sekaligus.

Detail
Meliputi
RAM threshold, priority Valorant, Valorant Safe Optimization, Performance/Game Mode, Background Apps toggle.
Gak termasuk
Latency Tweaks, Memory Compression, & Disable Telemetry bukan pure-registry — cara reset ada di komentar dalam file (buka pakai Notepad) atau di catatan bawah halaman.

Reset to Default (RAM saja) UNDO

Balikin threshold RAM saja ke default, tanpa nyentuh tweak lain.

Sebelum menjalankan apapun: buat System Restore Point dulu. File .reg → klik kanan → Merge. File .bat/.cmd → Run as administrator. Semua tool di sini opsional — jalanin cuma yang kamu ngerti efeknya.

Undo Latency Tweaks manual (Command Prompt as admin):
bcdedit /deletevalue useplatformtick
bcdedit /set disabledynamictick no
reg add "HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion\Multimedia\SystemProfile" /v "SystemResponsiveness" /t REG_DWORD /d "20" /f

Undo Memory Compression (PowerShell as admin): Enable-MMAgent -MemoryCompression

Undo Disable Telemetry (Command Prompt as admin): sc config DiagTrack start= demand & sc config dmwappushservice start= demand

Tidak dimasukkan ke toolkit ini (terlalu berisiko / gak nyambung ke tujuan optimasi game): mematikan Windows Search (WSearch) & Delivery Optimization (DoSvc) secara total, ganti proteksi exploit sistem-wide, ubah key NetworkProxy/TSDDD/MPEG2Demultiplexer, ganti cursor scheme system-wide, dan wrapper elevasi UAC otomatis. Kalau memang perlu, lakuin manual dan cuma kalau paham risikonya.
