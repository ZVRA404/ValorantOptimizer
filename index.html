03 // System Tools

Tweak & Cleanup

Tools tambahan buat bebersih sistem dan kurangi latency. Setiap tool dijelaskan: apa yang diubah, kenapa bisa bantu performa, dan hal yang perlu diperhatikan sebelum jalanin.

Performance Options + Background Apps + Game Mode DAMPAK: RINGAN

3-in-1: visual effect Windows, izin app background, dan Game Mode.

Apa yang diubah: Visual Effects Windows di-set ke "Adjust for best performance" (matiin animasi jendela, fade menu, shadow, dll) tapi tetap nyalain "Show thumbnails" & "Smooth edges of screen fonts" biar tampilan gak terlalu kasar. "Let Windows apps run in background" di-set jadi Force Deny (app UWP gak boleh jalan diam-diam di background). Transparency effects dimatikan. Game Mode diaktifkan otomatis.
Kenapa bantu: Kurangi kerja GPU/CPU buat render efek visual yang gak penting pas main, dan cegah app latar belakang makan resource CPU/RAM diam-diam.
Perlu tau: Setelah merge, sign out atau restart dulu baru kelihatan efeknya. Force Deny background apps bisa bikin notifikasi dari app UWP tertentu (misal app Store) telat muncul — kalau kepake buat kerja, ini biasanya gak masalah.

Valorant Safe Optimization DAMPAK: RINGAN

Game priority, disable Game DVR, transparency, Xbox services.

Apa yang diubah: Naikkan prioritas GPU/CPU untuk task game di Windows, matikan Game DVR (perekam Xbox Game Bar) dan transparency effect, serta men-disable 4 service Xbox Live yang gak kepake kalau kamu gak main lewat Xbox app (XblGameSave, XboxNetApiSvc, XboxGipSvc, XblAuthManager) plus beberapa service kecil (Font Cache duplikat, WIA scanner, Error Reporting, Compatibility Assistant, Event Collector, Maps Broker).
Kenapa bantu: Mengurangi overhead recording di background dan bebasin sedikit resource dari service yang jarang kepake.
Perlu tau: Printer & Bluetooth TIDAK disentuh — aman buat yang masih pakai keduanya untuk kerja. Kalau kamu pakai scanner (WIA) atau butuh Windows Error Reporting buat debug software kerja, edit dulu file ini sebelum di-merge (hapus section terkait).

Disable Memory Compression DAMPAK: SEDANG

Matikan fitur kompresi RAM bawaan Windows.

Apa yang diubah: Menjalankan Disable-MMAgent -MemoryCompression lewat PowerShell — mematikan fitur Windows yang otomatis mengompresi data di RAM biar muat lebih banyak.
Kenapa bantu: Kompresi RAM makan sedikit CPU tiap saat. Di PC dengan RAM besar (16GB ke atas), mematikannya bisa sedikit ringankan CPU karena gak perlu kompres/dekompres data terus-menerus.
Perlu tau: Kalau RAM kamu di bawah 8GB, JANGAN pakai ini — RAM kamu justru bakal lebih cepat penuh karena data gak dikompres lagi, dan malah bikin PC lag karena sering swap ke disk. Perlu klik "Yes" di prompt UAC (run as administrator).

Latency Tweaks DAMPAK: SEDANG

Disable Dynamic Tick & HPET, aktifkan platform tick.

Apa yang diubah: Lewat bcdedit, mematikan Dynamic Tick (fitur hemat daya CPU yang bikin timer sistem gak konsisten) dan mengganti sumber clock sistem dari HPET ke platform clock (biasanya TSC di CPU modern, lebih presisi & rendah latency).
Kenapa bantu: Timer sistem yang lebih presisi bisa bantu konsistensi frame time / input latency, terutama di CPU modern.
Perlu tau: Ini mengubah boot configuration, jadi WAJIB restart PC setelah dijalankan biar efektif. Kalau setelah restart PC berasa aneh (jarang terjadi di CPU modern, tapi bisa di hardware lama), jalankan Command Prompt (as admin) dan ketik bcdedit /deletevalue useplatformtick lalu bcdedit /set disabledynamictick no buat balikin.

Clean Temporary Files DAMPAK: RINGAN, AMAN

Hapus folder Temp, Windows Temp, dan Prefetch.

Apa yang diubah: Menghapus semua isi folder %temp%, Windows\Temp, dan Windows\Prefetch.
Kenapa bantu: Bebasin ruang disk dan bersihin file sampah aplikasi. Prefetch akan otomatis dibuat ulang Windows seiring waktu, jadi aman dihapus.
Perlu tau: Paling aman dari semua tools di sini — bisa dijalankan kapan saja tanpa perlu restart. Ada konfirmasi "pause" sebelum eksekusi, jadi kamu masih bisa cancel (Ctrl+C) kalau berubah pikiran.

Reset to Default RESET / SAFETY NET

Balikin SvcHostSplitThresholdInKB ke nilai default Windows.

Apa yang diubah: Mengembalikan SvcHostSplitThresholdInKB ke nilai default bawaan Windows (bukan berdasarkan RAM kamu).
Kapan dipakai: Kalau setelah pakai salah satu file RAM (bagian 01) ada yang berasa aneh atau kamu mau balik ke kondisi awal sebelum pernah pakai toolkit ini.
DILEWATI DARI TOOLKIT: Disable Process Mitigation gak dimasukkin. Script itu mematikan hampir semua proteksi exploit Windows (DEP, CFG, SEHOP, dll) di seluruh sistem — bukan cuma buat Valorant. Resikonya ke keamanan PC (rentan malware/exploit) jauh lebih besar daripada gain performa yang nyaris gak berasa. Kalau tetap ingin pakai atas risiko sendiri, cari referensinya sendiri di luar toolkit ini.
