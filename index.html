02 // Valorant Process Priority

Prioritas CPU Untuk Valorant

Atur prioritas proses VALORANT-Win64-Shipping.exe di Windows Task Scheduler. Semakin tinggi prioritas, semakin didahulukan CPU-nya dibanding proses lain.

MAX AGGRESIVE

High

Prioritas paling tinggi. Paling responsif, tapi proses background/kerja lain bisa sedikit tersendat saat game jalan.

RECOMMENDED

Above Normal

Seimbang — Valorant tetap diprioritaskan tanpa terlalu mengganggu aplikasi lain yang jalan bareng.

DEFAULT

Normal

Balikin prioritas Valorant ke standar Windows, sama kayak aplikasi lain.

03 // System Tools

Tweak & Cleanup

Tools tambahan buat bebersih sistem dan kurangi latency. Baca catatan tiap tool sebelum jalanin.

Valorant Safe Optimization

Game priority, disable Game DVR, transparency, Xbox services. Printer & Bluetooth tidak disentuh.

Disable Memory Compression

Matikan kompresi RAM Windows. Bisa bantu di PC RAM besar, tapi bisa bikin RAM cepat penuh di PC RAM kecil (<8GB) — hati-hati.

Latency Tweaks

Disable Dynamic Tick & HPET, aktifkan platform tick. Bisa bantu input latency, efeknya kecil dan tergantung hardware.

Clean Temporary Files

Hapus isi folder Temp, Windows Temp, dan Prefetch. Aman dijalankan kapan saja buat bebersih ruang disk.

Reset to Default

Balikin SvcHostSplitThresholdInKB ke nilai default Windows kalau ada yang aneh setelah tweak RAM.

DILEWATI: Disable Process Mitigation gak dimasukkin ke toolkit ini. Script itu matiin hampir semua proteksi exploit Windows (DEP, CFG, SEHOP, dll) di seluruh sistem, bukan cuma Valorant — resikonya ke keamanan PC jauh lebih besar daripada gain performanya. Kalau tetap mau pakai atas risiko sendiri, cari referensinya sendiri di luar toolkit ini.
[!] SEBELUM JALANIN APAPUN:
1. Buat System Restore Point dulu (Search > "Create a restore point").
2. File .reg → klik kanan → Merge, lalu Yes. File .bat/.cmd → klik kanan → Run as administrator.
3. Restart PC setelah import registry biar semua perubahan efektif.
4. Kalau ada software kerja yang bermasalah setelah tweak, jalankan "Reset to Default" atau restore point.
