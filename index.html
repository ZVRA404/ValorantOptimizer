Valorant Display & Graphics Settings

Auto-Apply GameUserSettings.ini TIMPA FILE SETTING

Set otomatis: resolusi 1920×1080, VSync off, semua grafik di posisi terendah — setup umum buat FPS maksimal. File lama otomatis di-backup sebelum ditimpa.

Detail
Apa itu
Nulis ulang file setting grafis Valorant sesuai konfigurasi di atas.
Wajib
Tutup total Valorant & Riot Client dulu sebelum jalanin, kalau tidak game bisa nimpa balik.
Risiko
Rendah — file lama otomatis dibackup (.bak). Kalau resolusi/monitor jadi aneh, atur ulang manual di Settings → Video dalam game.
Power Plan

Ultimate Performance LAPTOP: HATI-HATI

Aktifkan power plan tersembunyi Windows yang matiin hampir semua power-saving, biar hardware selalu di performa penuh.

Detail
Apa itu
Duplikat & aktifkan plan "Ultimate Performance" bawaan Windows.
Laptop
Baterai lebih boros & lebih panas — pakai cuma kalau dicolok charger terus.
Undo
Buka Control Panel → Power Options, pilih plan "Balanced" lagi.
System Tools

Performance + Background Apps + Game Mode UBAH TAMPILAN

Matiin efek visual Windows, blokir app background, nyalain Game Mode. Tampilan Windows jadi lebih polos.

Detail
Apa itu
Matiin animasi/transparency, blokir app UWP jalan di background, aktifkan Game Mode.
Kenapa
Kurangi beban CPU/GPU dari efek visual & app yang diam-diam jalan di belakang.
Risiko
App Store (kalender, notifikasi) mungkin telat update. Perlu restart setelah merge.

Valorant Safe Optimization AMAN

Game priority, disable Game DVR, transparency, Xbox services. Tweak inti buat Valorant.

Detail
Apa itu
Naikkan prioritas GPU/CPU game, matikan Game DVR & transparency, matikan service Xbox yang jarang kepakai.
Kenapa
Game DVR & service Xbox makan resource walau gak dipakai.
Risiko
Sangat rendah — printer & Bluetooth gak disentuh, aman dipakai sambil kerja.

Disable Memory Compression CEK RAM DULU

Matikan kompresi RAM Windows. Cek RAM kamu dulu di Task Manager sebelum pakai.

Detail
Apa itu
Matikan fitur Windows yang otomatis kompres data di RAM.
Kenapa
Ringankan CPU di PC dengan RAM besar (16GB+), gak perlu compress/decompress terus.
Risiko
Jangan pakai kalau RAM di bawah 8GB — RAM lebih cepat penuh, malah bikin lag.

Latency Tweaks UBAH BOOT CONFIG

Disable Dynamic Tick & HPET. Mengubah konfigurasi boot Windows, bukan setting biasa.

Detail
Apa itu
Ganti sumber clock/timer sistem biar lebih presisi.
Kenapa
Bisa kurangi micro-stutter di sebagian sistem — efeknya beda-beda tiap hardware.
Risiko
Ubah boot config lewat bcdedit. Wajib restart setelah dijalankan.

Clean Temporary Files AMAN

Hapus folder Temp, Windows Temp, Prefetch. Cuma bersih file sampah, gak ubah setting apapun.

Reset ALL to Default UNDO

Balikin semua tweak registry di atas ke default. Pakai kalau mau mundurin semua sekaligus.

Detail
Meliputi
RAM threshold, priority Valorant, Valorant Safe Optimization, Performance/Game Mode.
Gak termasuk
Latency Tweaks & Memory Compression bukan registry — cara reset ada di komentar dalam file (buka pakai Notepad).

Reset to Default (RAM saja) UNDO

Balikin threshold RAM saja ke default, tanpa nyentuh tweak lain.

Sebelum menjalankan apapun: buat System Restore Point dulu. File .reg → klik kanan → Merge. File .bat/.cmd → Run as administrator.

Tidak dimasukkan: Disable Process Mitigation — mematikan proteksi exploit Windows secara sistem-wide, risikonya terlalu besar untuk toolkit ini.
